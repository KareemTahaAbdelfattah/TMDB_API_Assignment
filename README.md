# TMDB_API_Assignment
A Postman API testing project for The Movie Database (TMDB) API, covering movies, TV shows, people, genres, authentication, watchlist actions, response validation, schema checks, sorting, filtering, and pagination using automated test scripts.  

This repository contains a Postman-based API testing project for The Movie Database (TMDB) API. It includes automated test scenarios for core TMDB endpoints such as movie details, TV details, person details, genres, discover/search flows, pagination, sorting, filtering, and authenticated account actions like watchlist management.  

It is designed for practicing API testing, writing Postman test scripts, validating JSON responses, and covering both functional and basic data integrity checks against the TMDB API.
